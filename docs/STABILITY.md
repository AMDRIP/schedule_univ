## Сохранение и восстановление

Перед записью проверяются JSON, структура справочников, версия схемы, опасные ключи
и ограничение 128 МБ. Старые проекты без schemaVersion остаются поддержанными.
Файл записывается в уникальный временный файл в той же папке, синхронизируется и
заменяет целевой через rename. При отказе rename оригинал не удаляется.
Сохранения одного пути сериализованы. Изменение проекта другой программой после
открытия блокирует сохранение: нужно открыть его заново или выбрать «Сохранить как».

Перед перезаписью старая версия попадает в `<проект>.schd.backups`. После успешной
записи остаются десять копий. При невозможности создать обязательную копию сохранение
прерывается без изменения оригинала. Повреждённая старая версия тоже сохраняется,
но помечается недоступной для восстановления. Неизменённый файл не создаёт лишних копий.

В настройках есть список копий, создание копии и восстановление. Можно выбрать
повреждённый проект отдельно от открытого. Перед восстановлением подтверждается
потеря несохранённых изменений; прежнее содержимое файла сохраняется в истории.
Автосохранение тоже атомарное, с собственной историей; при выходе оно не удаляется.
Восстановление автосохранения не перезаписывается автоматической загрузкой последнего проекта.

Резервные копии не являются внешним бэкапом: отказ диска может уничтожить обе версии.
Храните отдельную копию на другом носителе. Атомарность и сохранность при отключении
питания зависят от файловой системы и устройства; сетевые диски и синхронизация облака
не дают тех же гарантий, что локальная файловая система. Символические ссылки на проекты
не принимаются. Новые схемы проекта не открываются с тихой потерей данных.

## Установка и безопасность

Мастер NSIS: приветствие RC, выбор пользователя/каталога, сводка хранения данных,
ярлыки, ассоциация .schd и запуск после установки. appId сохранён для совместимости
обновлений. Проекты и пользовательские данные не удаляются деинсталлятором.
Цифровая подпись возможна при предоставлении сертификата издателя через CI secrets.
Без сертификата установщик остаётся неподписанным; RC не является сертификатом безопасности.

Приложение не загружает скрипты и шрифты с CDN. Включены CSP, sandbox, contextIsolation,
проверка отправителей всех IPC, запрет webview, разрешений устройств и внешней навигации
в привилегированном окне. HTTPS-ссылки открываются внешним браузером. Печать использует
изолированное окно без preload, Node и исполнения скриптов; данные экранируются.
Права записи ограничены проектами, выбранными через приложение. ИИ-ключи остаются
сессионными; токен Telegram шифруется средствами ОС. Роли не заменяют авторизацию.

## Проверки

CI Windows на push/PR: npm ci, audit, TypeScript, unit/integration, security, сборка,
Electron/Playwright и проверки ASAR/worker/бота. Actions закреплены SHA, права contents:read,
автоматической публикации и автоматических git commit/push из npm scripts нет.
Сборка установщика проверяет компиляцию кастомных NSIS-страниц и метаданные пакета.
Установка поверх реального приложения пользователя тестами не выполняется: для полного
цикла install/upgrade/uninstall требуется отдельная чистая Windows VM.
Все тесты автоматические. Ручные тесты не проводятся.
